Спецификация экранов
1. Главная
Статистика: сколько заявок ожидают ответа
Календарь — интеграция с Google, на этом этапе просто заглушка
Счётчик проектов, которые "стоят" — не было смены этапа больше N дней
Счётчик менеджеров, готовых взять новый проект
Состав раздела открыт — возможны дополнения позже
2. Команда
Список всех членов команды, строки оформлены как скруглённые прямоугольники таблицы
В каждой строке: ФИО, занятость, статус
У каждой строки — кебаб-меню (три точки) с действиями:
дать проект
перевести в другую команду
выгнать менеджера
посмотреть профиль
перейти к его проектам
Возможность добавить члена в команду, если нужно
Раскрывающееся меню вниз у строки — для беглого просмотра проектов этого менеджера, не уходя со страницы
3. Менеджеры
Список свободных менеджеров (без команды)
Сироты (менеджеры, чей руководитель выбыл) — отдельной пометкой сверху списка
Возможность добавить менеджера себе в команду прямо отсюда
4. Проекты
Две вкладки: Свои и Чужие
Вкладка "Чужие" по умолчанию пуста; заявки в ней появляются только при осиротевших случаях и когда проект передают — передача дублируется уведомлением, а не просто тихо всплывает в списке
В каждой из вкладок — фильтры:
по вузу
по этапу
черновик / не черновик
завершён / не завершён
Создание проекта переключает его в черновики; при назначении менеджера проект переходит в "не черновик" (активные)
5. Заявки
Отображается всё, что требует ответа — согласие/несогласие с комментарием
Каждое такое событие дублируется уведомлением
